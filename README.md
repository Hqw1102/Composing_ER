# 📊 Excel 数据字典转 ER 图工具 (Excel to ER Diagram Generator)

这是一个基于 Python 的自动化工具，能够读取标准的 Excel 数据字典文件，并自动生成结构清晰、带有颜色分类和层级分组的实体关系图（ER图）。

该工具特别适合用于大型跨系统企业级架构（如 SAP, RFQ, K2 等）的数据库梳理，帮助开发团队和架构师快速实现数据表关系的可视化。

## ✨ 核心特性

- **🚀 自动读取与解析**：直接读取 `数据字典_汇总.xlsx`，自动清理空值和不规范数据。
- **🎯 智能字段过滤**：为了保持图表整洁，**仅展示主键 (PK)、外键 (FK) 以及被引用的字段**，隐藏普通业务字段。
- **🗂️ 智能分组与聚类**：
  - 支持顶层大组划分（例如将 `RFQ`, `partRelease`, `SAP` 聚类在同一个大组中）。
  - 按所属子系统自动将表划分到对应的虚线框（Cluster）内。
- **🎨 自动配色系统**：内置系统颜色映射表，自动为不同系统的表头分配不同的背景色，支持自定义扩展。
- **🔗 标准关系连线**：自动识别外键依赖，并使用标准的 Crow's foot（乌鸦脚）表示法绘制 `1 对 N` 的表级关系连线。
- **🌐 完美支持中文**：自动生成唯一的内部标识（ID），彻底解决 Graphviz 渲染中文字符作为节点 ID 时可能引发的报错问题。
